01 / PROJECT OVERVIEW

项目概览

本项目为使用 Godot 引擎独立制作的生存冒险 RPG Demo。围绕「安全屋 → 主枢纽 → 分区探索 → 目标回收 → 死亡结局」组织研究所关卡，完成 26 个房间场景的白盒与核心功能。

使用「单房间单场景」结构，实现门交互、场景切换、固定／跟随视角、HUD、背包、敌人与 Boss 结局，使纸面动线落地为可实机游玩的 Demo。

02 / LEVEL LAYOUT

研究所地图与空间连接

将大厅与长走廊作为主枢纽，通过门禁卡、单向反锁门、捷径与永久堵塞门控制探索动线，构建往返探索回路。线索与可选调查为玩家理解目标提供方向。

地图包含一层研究所空间与二层走廊、小会议室，并区分敌人、交互物品与物资。将空间连接与交互条件放在同一张图中，可以同时查看可探索区域、关键物品位置，以及后续开通的通路。

03 / EXPLORATION & INTERACTION

门禁、关键物品与文件线索

地图中的门禁卡、保险丝、配电箱与报告厅音箱形成多种交互节点。演示展示了关键物品与文件查看界面，文件内容为设备与场景交互提供线索。

报告厅音箱使用指南中说明：恢复电力、确认音源，再通过主控设备打开音箱。空间探索与文件阅读由具体的场景目标连接起来。

04 / ENEMIES & RESOURCES

敌人与物资分布

将敌人按应对方式分为「必杀、可选击杀、不鼓励击杀、机制规避」四类，围绕手枪随机伤害设计 3—4 枪击杀模型。根据强制战斗和可选探索配置子弹数量区间，目标是形成「资源够用但不宽裕」的生存压力。

地图用不同符号标出丧尸、交互物品与物资。弹药和急救包分布在走廊及各个房间；演示中的剩余子弹与身体状态反馈，可与地图中的敌人和补给位置对照查看。
